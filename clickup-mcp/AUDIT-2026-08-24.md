# Deep audit, 2026-08-24

Two independent swarms over the panel codebase: five Codex (gpt-5.6-sol,
xhigh, read-only) passes and a 56-agent Claude workflow with adversarial
verification (36 confirmed of 37, 1 refuted). Findings that appeared in both
were treated as high-confidence. Everything below was verified against the
actual code before it was written down.

## Fixed (14 commits, `879bf97..HEAD`)

Reliability of the public send path, crash-safety, one money leak, two
injection hardenings, and the build gate. Each is one behaviour, tested.

| # | commit | what it stops |
|---|---|---|
| 1 | `send-path: a reply that cannot be recorded is not reported as sent` | a hand-written question with no status line was answered publicly, stayed open, and got a second public reply on the next run |
| 2 | `bulk: validate and store an edited reply before marking it sending` | an empty single-send wedged the row in "sending" forever, deadlocking every bulk action; a hand edit was lost on reload |
| 3 | `bulk: the send worker rechecks each row, and polish holds off mid-send` | polishing a queued row mid-send posted stale text, then reverted a sent row to "drafted" |
| 4 | `bulk: claim a run atomically so two starts cannot interleave` | two Draft clicks started two workers over one queue; a draft landed on the wrong row and was posted against the wrong question |
| 5 | `state: durable Panel JSON is written atomically` | a crash mid-write reset the spend ceiling to zero, lost a reviewed queue, or re-billed a cached draft |
| 6 | `bulk: draft only the questions actually waiting` | a model was paid to draft replies to praise, out-of-scope and unknown |
| 7 | `discord, polish: two smaller send-path holes` | replies to split Discord questions failed; a comment could close the polish fence and inject instructions |
| 8 | `build: refuse to publish a page whose script fails node --check` | a collapsed escape shipped a 5 MB page where no button worked |
| 9 | `bulk: drop the dead preview action left by the picker merge` | dead route + unreachable branch from the card merge |
| 10 | `bulk: the review card counts a single send as busy and keeps edits` | a tab opened mid-send stopped polling; Back-to-queue and reload discarded unsent edits |
| 11 | `build: substitute page placeholders in one pass` | a comment containing `__LOOKUPS__` corrupted the page's JSON and killed every interaction |
| 12 | `send-path: two Retry clicks cannot post the same answer twice` | the /resend path checked "already posted" on a stale read outside the lock |

## Deferred, ranked. Each is real and verified; each was left because it
changes behaviour, touches the parser across ~1500 existing questions, or is
a design decision that is yours to make.

### High

1. **Drafting can read customer PII and echo it into a public reply.**
   The draft/polish subprocess runs with `cwd=VAULT` and `Read`/`Grep`
   allowed, and `Panel/` (emails, payment amounts) and `Customers/` are
   under the vault. A poisoned note can instruct the model to read
   `Panel/patreon-members.json` and paste it into a draft that is then sent
   publicly. The random fences protect the text passed inline, but not what
   the model opens itself.
   Recommendation: pass the drafting CLI a deny rule for `Panel/**` and
   `Customers/**` (and credentials), or point it at a read-only corpus that
   physically excludes them. Low behavioural risk, high value; deferred only
   because it touches the AI provider invocation, which your rules say to
   change deliberately. `panel.py` around the `start_ai_job` / CLI flags.

2. **The inbox parser can be steered by comment content.**
   (a) a comment whose text begins `### 2026-08-24 ...` forges a second
   question-block header, leaving a real source-less block empty;
   (b) an unbalanced ``` in a comment masks every later question in the
   file; (c) a prose line matching a field pattern (`status: why is this
   broken?`) is stripped from the question text.
   Recommendation: length-delimit or escape collected bodies, and record the
   exact header-line span so only those lines are excluded from prose. Needs
   a golden-file test over the current inbox first; risky to touch blind.
   `panel.py` `_iter_inbox_blocks` / `parse_questions` (~415-478),
   `collect_youtube.py` ~610, `collect_discord.py` ~565.

3. **Collectors can overwrite a complete snapshot with a partial one.**
   A truncated YouTube comment fetch (>10 pages), a `commentsDisabled`
   under `--force`, or a Discord/Patreon member page that fails mid-
   pagination all still write their partial result with a fresh mtime, and
   the panel's health check trusts mtime. Discord incremental `after`
   pagination can also skip a backlog; embedded YouTube replies can be
   incomplete and trigger a duplicate answer; a staff reply arriving after a
   question was collected never flips it to answered.
   Recommendation: have fetches return `{items, complete, reason}` and never
   replace a complete file with an incomplete one. `collect_youtube.py`,
   `collect_discord.py`, `collect_patreon.py`. Manual tools, so lower blast
   radius than the live panel, but real data loss.

4. **`errors="replace"` becomes permanent corruption on rewrite.**
   A cp1252 byte in a hand-authored question is decoded to the replacement
   char, and the next status flip or collector append rewrites the whole
   file in UTF-8 with that char baked in. Decode strictly with an explicit
   cp1252/utf-8-sig fallback and refuse to write replacement characters.

5. **"Open" still has two definitions.** The paid path (bulk drafting) is
   fixed. The KB build, the export, and the answer-rate math still treat
   anything not "answered" as open, so praise and out-of-scope can inflate
   the queue and depress the answer rate. Consolidate onto `OPEN_STATUSES`
   (now defined in `panel.py`) and embed the same set into the page's JS.
   Touches answer-rate numbers, so verify against current figures first.

6. **`--vault X` does not relocate two Panel stores.** `AI_SPEND_PATH` and
   `BULK_STATE_PATH` bind to the default vault at import, before `main()`
   applies `--vault`, so a non-default vault reads spend and bulk state from
   `F:\LocoDev Vault`. Low real-world impact (the watcher uses the default),
   real latent bug. Derive both paths from the resolved `VAULT`.

7. **Catalog drift, `panel.py` vs `build_vault.py`.** Character Leaning is
   in the panel catalog but not `build_vault.py`; the five facets are
   duplicated. A freshly built vault omits a system the dashboard offers.
   Move catalog + facets into one shared module.

### Medium

8. **Distinct failures still collapse into one category** in several places:
   malformed YouTube/admin JSON labelled "network"; admin HTTP 429 labelled
   "auth"; Discord 401/5xx labelled "channel not found"; forum failures
   silent. Return a small category enum and map it once.

9. **`question_filter.classify` edge cases.** The offer guard fires before
   problem evidence ("It doesn't work; let me know if you need details" ->
   no classification); a trailing URL's `?` makes praise look like a
   question; "networked" matches the "worked" praise substring; a leading
   `@mention` and unicode `?` / curly apostrophe cause false negatives.
   Tokenise and strip URLs; normalise unicode punctuation. Each needs a
   test row.

10. **`server.py` MCP attachment tools** (`anexar_arquivo`, `anexar_url`)
    take an arbitrary local path or URL with no restriction: an injected
    instruction in an agent session with this MCP enabled can upload `.env`
    or a `Panel/*.json`, or SSRF `http://127.0.0.1:8765/...`. Restrict to a
    staging dir; allow only HTTPS approved hosts, reject loopback/private.

11. **OAuth callback has no `state`/PKCE** (`youtube_oauth_setup.py`), and
    tokens fall back to plaintext `.env` when `keyring` is absent (it is not
    a hard dependency). Add state+PKCE; fail closed rather than write the
    refresh token in plaintext.

12. **Vault markdown writes are non-atomic** (`update_question_status`,
    `append_answered_log`, the resend mark). A crash mid-write truncates a
    note. The JSON state is now atomic (commit 5); the markdown side is the
    same fix applied to those write sites.

### Low (cleanup)

13. Dead renderers after the client-row migration: `_mini_thumb`, `_roles`,
    `_st_class`, `_pill`, `_diff_pill`, `CHANNELS`, `STATUS_CLASS`; QDATA
    ships `status` twice and duplicates `who` as `asker`.
14. `history.json` still records `cov`/`crit`/`complete` that nothing reads.
15. The tile grid CSS is still sized for the five removed tiles.
16. YouTube permalink and short-link URLs are built in four places with
    different escaping.
17. Restored filter/page state can disagree with the visible controls (age
    filter active while "Any time" shows selected; page size restored but
    the select still reads 25).

## Refuted (dropped by verification)

- "`_child_env` strips secret env vars but Read/Grep can still exfiltrate
  secret files" — the exfiltration channel (reading `.env`) is already
  outside the drafting `cwd` and not what the vault-PII finding (High #1)
  covers; the specific claim did not hold on the working tree.
